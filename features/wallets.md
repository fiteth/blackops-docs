# Wallet Analytics

Wallet Analytics helps subscribers review tracked wallets on Solana, Robinhood, and TON.

## Browse wallets

1. Open **Wallets** from subscriber navigation.
2. Choose an active chain: Solana, Robinhood, or TON.
3. Switch between **Max** and **Realized**.
4. Use **Exclude Copytraders** and **Exclude Rug Traders** as needed.

Sort using column headers. Use per-column filters to narrow results. Use **Columns** to choose visible columns.

Select **Clear Filters** to reset filters. Use **Export CSV** to download the current results. Use pagination to browse more rows.

## Open wallet details

Select the wallet address link to open **Wallet Details**.

On **Wallet Details**, you can:

* Select **Back to Wallets**.
* Copy the address or open the chain explorer.
* Switch between **Max** and **Realized**.
* Sort token history.

Review wallets and tokens independently before making a decision.
